# Operit 2 Guides

Welcome to the documentation section dedicated to **Operit 2**.

Operit 2 is a **cross-platform product**. **iOS and macOS public betas are available** through [TestFlight](https://testflight.apple.com/join/hzq2xRrH). Other platforms are in private testing, with access opening gradually. Usage tutorials will be added alongside generation-two releases. This section does not reuse generation-one setup steps or screenshots, so instructions for different generations are not confused.

## One shared plugin market

Operit 1 and Operit 2 use the same [plugin market](/#/market) and marketplace account. **A shared catalog does not mean every plugin supports every app version.** Check the app-version requirements and author notes before installing.

Developer resources remain in the [shared plugin developer docs](/#/developers/plugins).
