# Chat History Selective Export

The current "chat history" export writes all sessions into a single archive. The published entry point has been changed to first select one or more sessions, while keeping full export capability via select-all.

This change only adjusts the chat history export flow, export filtering, and corresponding copy in settings. Archive format, import flow, database backup, and raw snapshots are out of scope.
