# Operit Python Project

This is a Python project created with Operit.

## Quick Start (Using a Virtual Environment Recommended)

### 1. Create and Activate the Virtual Environment
```bash
# Create the virtual environment
Click the "Create Virtual Environment" button

# Activate the virtual environment (required every time you open a terminal)
Click the "Activate Virtual Environment" button
```

### 2. Install Dependencies
```bash
Click the "Install Dependencies" button
```

### 3. Run the Program
```bash
Click the "Run main.py" button
```

### 4. Start the Web Server (Optional)
```bash
Click the "Start HTTP Server" button
Then click "Browser Preview" to view the result
```

## Project Structure

- `main.py` - Main program entry point
- `requirements.txt` - Python dependency list
- `venv/` - Virtual environment directory (created later)
- `.operit/config.json` - Operit workspace configuration

## About Virtual Environments

Benefits of a virtual environment:
- ✅ Isolates project dependencies
- ✅ Avoids package version conflicts
- ✅ Makes project migration easier

## Common Commands

- `Create Virtual Environment` - Run on first use
- `Activate Virtual Environment` - Activate before each use
- `Install Dependencies` - Install the packages in requirements.txt
- `View Installed Packages` - View the package list of the current environment

## Tips

- Python 3.8+ is recommended
- Create and activate the virtual environment on first use
- Re-run after modifying code to see the effect
