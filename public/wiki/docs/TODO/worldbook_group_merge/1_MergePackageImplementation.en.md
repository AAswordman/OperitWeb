# Merge Package Implementation

## Old Implementation

World book data is stored in the stable package's config directory. The management UI shows content as a flat entry list,
keeps no grouping records, and cannot duplicate entries after creation.

## Changes

Sync the grouped source and compiled artifacts from the downloaded `com.operit.worldbook_plus.toolpkg`,
keeping the stable package ID. Change UI routes inside the archive that depend on `com.operit.worldbook_plus` to
`com.operit.worldbook`, to avoid navigating to a nonexistent route after installation.

## Expected Results

- The stable package is upgraded in place to `1.2.0`
- Existing entry data remains readable
- Grouping data is additionally written to `groups.json` in the same config directory
- The management UI can manage groups and duplicate entries
