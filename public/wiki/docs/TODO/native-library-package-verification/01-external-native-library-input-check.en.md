# External Native Library Input Verification

## Original Behavior

`liboperit_ripgrep.so` is not generated by Gradle or CMake, but is compiled with the Rust toolchain by `tools/native_ripgrep/build_native_ripgrep.ps1` and copied into the application's JNI directory. FFmpegKit is also built independently by `tools/ffmpeg/build_ffmpeg_kit_wsl.sh`, then imported as `app/libs/ffmpeg-kit-local.aar`. When these inputs are missing, AGP can still continue packaging.

## Change Intent

Make `preBuild` depend on a dedicated verification task. That task checks the Rust build artifact `app/src/main/jniLibs/arm64-v8a/liboperit_ripgrep.so`, and reads the FFmpegKit AAR to confirm that all 10 of its arm64 native libraries are non-empty entries.

## Expected Result

- When `liboperit_ripgrep.so`, the FFmpegKit AAR, or its arm64 native entries are missing or zero-sized, application packaging fails
- The error message points to the corresponding generation or import script
- Native libraries provided by CMake, AARs, or submodules are not constrained

## Completion Status

[DONE] The external native input verification has been registered in the application Gradle script and wired into `preBuild`.
