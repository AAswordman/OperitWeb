# Dynamic Thinking Options

The current version has not been released yet, so the global fixed five-level thinking intensity contract is removed. The thinking slider is now determined by the real options returned by the current Provider, protocol, and model, and Android, WebChat, and request serialization share option ids.

Scope: thinking option mapping, settings persistence, Android/WebChat sliders, Provider request parameters.

The Provider mapping and model catalog capability boundary are recorded in [03-provider-capability-mapping.md](03-provider-capability-mapping.en.md).
